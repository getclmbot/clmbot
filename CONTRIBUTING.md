# Contributing to getclmbot

The clmbot product source code is not currently public. This repository accepts usage questions, reproducible problem reports, feature and integration proposals, deployment experience, and documentation corrections. It does not accept pull requests for the clmbot product source code.

## Choose the right channel

- **Q&A:** installation, configuration, certificate discovery, and automated update questions;
- **Ideas:** feature, upstream service, or deployment-target proposals;
- **Show and tell:** real deployment workflows, sanitized configurations, and verified solutions;
- **Issues:** reproducible clmbot defects with a clear scope; and
- **security@clmbot.org:** unresolved security vulnerabilities.

## Before posting

- Search the documentation, Discussions, and Issues first.
- Include the clmbot version, operating system, CPU architecture, and deployment target.
- Separate the expected result, actual result, and troubleshooting already attempted.
- Remove access credentials, private keys, complete certificates, customer information, internal addresses, and unsanitized logs.
- For adaptation requests, include the product version, official interface documentation, and any reproducible test conditions you can provide.

Community maintenance is provided on a best-effort basis. No response time, processing order, or service level is guaranteed.

By participating, you agree to follow the [Code of Conduct](CODE_OF_CONDUCT.md).
