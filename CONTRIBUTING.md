# Contributing to clmbot

Thanks for helping improve clmbot. Contributions are welcome for code, documentation, translations, testing, platform research, and reproducible bug reports.

## Before opening an issue

- Search existing Issues and Discussions first.
- Remove access keys, private keys, certificates, customer domains, and personally identifiable information.
- Use GitHub Discussions for questions and ideas; use Issues for reproducible bugs or concrete work items.
- Do not report security vulnerabilities in public Issues. See [SECURITY.md](SECURITY.md).

## Pull requests

- Keep each pull request focused on one change.
- Explain the problem, the approach, and how you tested it.
- Update relevant documentation when behavior changes.
- Do not claim a platform is supported without test evidence and maintainer confirmation.

By contributing, you agree to follow the [Code of Conduct](CODE_OF_CONDUCT.md).
